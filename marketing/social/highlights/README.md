# TRENIKO — Instagram highlight covers

Five covers, 1080 × 1920 (Story format), white ground, `#0ea5e9` line icons,
uniform 18-unit stroke weight so the five read as one icon family.

| File | Highlight title | Icon |
|---|---|---|
| `highlight-product.png` | PRODUCT | app window with a title bar |
| `highlight-features.png` | FEATURES | 2 × 2 module grid |
| `highlight-trainers.png` | FOR TRAINERS | single person |
| `highlight-updates.png` | UPDATES | arrow up in a circle |
| `highlight-faq.png` | FAQ | question mark in a circle |

## Why there is no text in the covers

Instagram crops a highlight cover to a **circle** and displays it at roughly
60 px. Any text baked into the image is either cropped away or unreadable. The
label is carried by the highlight's **title** instead (15 characters max), which
is what actually renders under the circle.

Each icon is centred on the image so it survives the circular crop, and each was
checked as a 200 px circle before export.

## Before creating these highlights

A highlight can only be created from an existing Story, and Stories cannot be
published from Instagram web — this needs the mobile app.

**Do not create empty or filler highlights.** Each one should be added only when
there is genuine content to put in it:

- **PRODUCT** — once there are product walkthrough Stories
- **FEATURES** — once individual features have been covered
- **FOR TRAINERS** — once there is onboarding/"is this for me" content
- **UPDATES** — once there is a real release to announce
- **FAQ** — once real questions have actually been asked

`RESULTS` is intentionally absent. Do not create it until real, attributable
customer proof exists.
